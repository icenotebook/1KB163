# Data provenance and import assumptions

Raw input files belong in `data/raw/`. Preserve their original bytes. No real data is generated by the workshop, and missing inputs are reported rather than replaced with synthetic spectra.

## Raman: Beryl R110118

- Source: [RRUFF sample R110118](https://rruff.info/R110118), linked by the NIRPY tutorial.
- Expected file: `Beryl__R110118__Broad_Scan__780__0__unoriented__Raman_Data_RAW__22217.rruff`.
- [Original tutorial download](https://rruff.net/tmp_rruff/Beryl__R110118__Broad_Scan__780__0__unoriented__Raman_Data_RAW__22217.rruff).
- Axis: Raman shift, cm^-1. Intensity is treated as arbitrary units unless the downloaded header documents another scale. Filename indicates 780 nm excitation; confirm against the source record.
- Import: preserve `##` header lines as metadata; parse comma-separated numeric axis/intensity pairs until `##END=`. Require finite values and a strictly increasing, approximately uniform axis.
- Access check on 6 October 2026: original download returned HTTP 404. If unavailable, obtain the same raw spectrum through the sample record; record its new URL and checksum. If filename or format changes, explicitly edit the parameter cell and loader after inspecting the file.
- Attribution: RRUFF Project. Redistribution license has not been established in this pilot; consult the repository terms before including a downloaded copy in a student distribution.

## XRF: historical ink

- Zamalloa Jara, M. A.; Luizar Obregon, C.; Gonzales Bellido, J. F.; Rojas Arizapana, F. L.; Chura Huayllani, Y. J. (2023), *Elemental analysis XRF of inks (1778–1825)*, Mendeley Data, version 2.
- DOI: [10.17632/228pwkw55h.2](https://doi.org/10.17632/228pwkw55h.2).
- Dataset: https://data.mendeley.com/datasets/228pwkw55h/2
- License displayed by repository: **CC BY 4.0**. Retain attribution; generated corrected spectra are modifications of source data.
- Expected file: `Raw data-ancient inks_16Ene2021.xlsx`.
- Import follows the tutorial's `spectra data` sheet, `skiprows=1`, columns A:C. Zero-based row positions 2 and 3 of selected column C give offset and increment; counts start at position 20. Each is explicitly recorded in run metadata. Inspect these rows in Excel or the notebook before accepting them.
- Axis: energy in keV; signal: counts. Confirm these units and acquisition conditions against the workbook metadata. Additional workbook spectra are outside the initial pilot selection.
- Access check on 6 October 2026: the dataset page was available, but the programmatic download probe did not return the workbook. No XRF source file was obtained.
- A missing workbook leaves this section inactive. Download the exact workbook from version 2 and place it in `raw/`, then restart and run all.

## Synthetic teaching spectrum

Generated in `src/baseline.py` from three Gaussian peaks, a smooth baseline and seeded Gaussian noise. Units are arbitrary, not Raman or XRF. The seed and equations are recorded in exported metadata. Ground truth is retained for baseline RMSE and peak-window area comparisons. This adds a controlled experiment; it is not a substitute for validating a method on analytical samples.

## Records

`download_manifest.json` records any successful source downloads. Each executed run additionally hashes its inputs and records package versions and parameters in `outputs/<run-label>/run_metadata.json`. Empty download records mean no source file was obtained. Manually supplied files are still hashed during execution; add their retrieval date, URL, acquisition metadata and license here.
